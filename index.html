Learning Crumbs Uploader

A private tool that uploads the Learning Crumbs channel's own quiz videos to YouTube

Learning Crumbs Uploader is a small private program used only by the owner of the Learning Crumbs YouTube channel. It is not offered to anyone else and has no public sign-up.

What it does

The owner makes short educational quiz videos on their own computer. This tool uploads those videos to the owner's own YouTube channel using the YouTube Data API. For each video it sets:

  • the title, description and tags
  • a scheduled publish time
  • a custom thumbnail
  • the playlist for the quiz topic
  • the audience setting (not made for kids) and the category (Education)

Why it asks for access to a Google account

The tool asks for one permission, "Manage your YouTube account", only so it can upload the owner's own videos to the owner's own channel, set their thumbnail and schedule, and add them to the owner's playlists. It uses this access for nothing else.

What it does not do

  • It does not access any other person's YouTube account.
  • It does not show, collect or analyze YouTube data about viewers or other channels.
  • It does not sell or share any data.
