Privacy Policy

Learning Crumbs Uploader. Last updated: 27 September 2026.

Learning Crumbs Uploader ("the tool") is a private program used only by the owner of the Learning Crumbs YouTube channel to upload the owner's own videos. It is not offered to the public.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What information the tool accesses

  • When the owner signs in with Google, the tool receives an access token for the owner's own YouTube channel.
  • With that token it uploads the owner's videos and thumbnails, sets their title, description, tags, publish time, audience and category, and adds them to the owner's playlists. It reads the owner's playlist names to find the right playlist.
  • It does not access information about viewers, subscribers, comments or any other channel.

How information is stored

  • The sign-in token is stored only in a private file on the owner's own computer.
  • The videos, thumbnails and texts are the owner's own files on the owner's own computer.
  • Nothing is stored on any server run by the tool, because the tool has no server.

Sharing

The tool does not sell, share or transfer any information to anyone. Information is sent only to YouTube (Google), as needed to upload the owner's videos.

How to remove access

Access can be removed at any time on the Google security settings page: https://security.google.com/settings/security/permissions. Deleting the token file on the owner's computer also removes the tool's access.

Changes

If this policy changes, the new version will be posted on this page with a new date.
